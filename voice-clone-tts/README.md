# voice-clone-tts

Озвучка произвольного текста голосом из MP3-файла.

На вход подаются два параметра: **запись голоса** (mp3/wav/m4a/…) и **текст**.
Скрипт распознаёт запись (Whisper), определяет по ней язык, строит из неё
профиль диктора, расставляет в тексте ударения и `ё` через
[silero-stress](https://github.com/snakers4/silero-stress) и синтезирует речь
клонированным голосом. Русский и английский работают из коробки, другие языки
добавляются конфигом.

```
mp3 ──► декодирование ──► ASR (язык + транскрипт) ──► выбор чистых сегментов ──► профиль диктора
                                                                                     │
текст ──► нормализация ──► ударения (silero-stress) ──► нарезка на чанки ────────────┤
                                                                                     ▼
                                                                          backend.synthesize
                                                                                     │
                                                                  склейка · громкость · файл
```

## Быстрый старт

```bash
pip install -e '.[all]'                 # или см. «Установка» ниже
export VCTTS_ACCEPT_COQUI_LICENSE=1     # подтверждение лицензии весов XTTS

# самый короткий путь: голос + текст -> wav
vctts speak -v sample.mp3 -t "Привет! Это мой клонированный голос." -o out.wav

# язык не указываем — он определяется по записи
vctts speak -v sample.mp3 -f article.txt -o article.mp3

# один раз построить профиль и потом переиспользовать (быстрее)
vctts profile build sample.mp3 -o profiles/anna
vctts speak -p profiles/anna -t "Второй текст тем же голосом." -o second.wav

# посмотреть, что реально уедет в модель, без синтеза
vctts speak -p profiles/anna -f article.txt --dry-run

# только расстановка ударений
vctts stress "Старинный замок на горе, а на двери замок"
# -> Стар+инный з+амок н+а гор+е, +а н+а двер+и зам+ок
```

## Установка

```bash
pip install -e .                # ядро: numpy, soundfile, soxr (без нейросетей)
pip install -e '.[stress]'      # + silero-stress (torch) — ударения и ё
pip install -e '.[asr]'         # + faster-whisper — распознавание и детект языка
pip install -e '.[xtts]'        # + coqui-tts — клонирование голоса (XTTS-v2)
pip install -e '.[silero]'      # + Silero TTS (готовые голоса, без клонирования)
pip install -e '.[all]'         # всё сразу
```

`ffmpeg` нужен только если ваша сборка `libsndfile` не умеет читать входной
формат: MP3 в libsndfile ≥ 1.1 читается и пишется без него.

Проверить, что доступно в текущем окружении:

```bash
vctts backends     # ✓/✗ по каждому движку + команда установки
vctts languages
```

## Бэкенды

| backend  | клонирует голос | языки | ударения `+` | частота | лицензия весов |
|----------|-----------------|-------|--------------|---------|----------------|
| `xtts` (по умолчанию) | да, zero-shot | ru, en + 15 других | нет (снимаются, `ё` остаётся) | 24 кГц | Coqui CPML, **некоммерческая** |
| `silero` | нет, пресет-голоса | ru, en, uk | да, нативно | 48 кГц | MIT |
| `dummy`  | нет | любые | нет | 24 кГц | — |

* **xtts** — основной путь. Zero-shot клонирование: модель принимает несколько
  секунд эталонной речи и говорит этим голосом. Веса скачиваются при первом
  запуске (~1.8 ГБ) и распространяются по
  [Coqui Public Model License](https://coqui.ai/cpml) — только некоммерческое
  использование. Пока вы не подтвердите это через
  `VCTTS_ACCEPT_COQUI_LICENSE=1` или `--accept-coqui-license`, скачивание не
  начнётся.
* **silero** — голос не клонирует, зато единственный, кто ест разметку
  ударений silero-stress как есть (`гот+ов`). Удобен как быстрый CPU-baseline
  и чтобы услышать, что именно даёт шаг с ударениями.
* **dummy** — без моделей вообще: гудок на частоте основного тона диктора.
  Нужен для тестов конвейера и CI.

Свой движок добавляется одним классом — см. «Расширение».

## Ударения и `ё` (silero-stress)

Для русского текста ударения решают больше, чем кажется: без них модель читает
омографы наугад. `silero-stress` покрывает ~4 млн словоформ и ~2.2 тыс.
омографов и заодно восстанавливает `ё`. Разметка ставится **перед** ударной
гласной:

```
Старинный замок на горе, а на двери замок
  ->  Стар+инный з+амок н+а гор+е, +а н+а двер+и зам+ок
```

Движки относятся к этой разметке по-разному, поэтому конвейер хранит текст во
внутреннем `+`-формате, а каждый бэкенд получает тот вид, который понимает
(`native_stress_style`):

| `--stress-style` | что уходит в модель | кому |
|------------------|---------------------|------|
| `plus`  | `гот+ов` | Silero TTS и большинство русских G2P |
| `acute` | `гото́в` (U+0301) | фронтенды, понимающие комбинирующий акут |
| `none`  | `готов`, но `ё` сохраняется | XTTS — символ `+` он не видел при обучении |

Порядок шагов важен: silero-stress не раскрывает цифры, поэтому нормализация
чисел идёт **до** расстановки ударений. Нормализатор разворачивает числа,
даты, проценты, валюты, время и сокращения:

```
В 2024 г. замок стоил 1 234 567 руб. Встреча в 10:30.
  ->  В две тысячи двадцать четвёртом году замок стоил один миллион двести
      тридцать четыре тысячи пятьсот шестьдесят семь рублей. Встреча в десять тридцать.
```

Отключается через `--no-stress` / `--no-normalize`, отдельные слова — через
`--ignore-word СЛОВО`.

## Профиль диктора («обучение»)

`vctts profile build` — это шаг адаптации под голос. Важно понимать, что это
**few-shot адаптация, а не дообучение градиентом**: из записи извлекаются
эталонные фрагменты и условные представления диктора, веса модели не меняются.
Для XTTS этого достаточно, чтобы узнаваемо скопировать тембр с 30–60 секунд
речи.

Что происходит внутри:

1. запись декодируется в моно 24 кГц;
2. считается отчёт о качестве (длительность, клиппинг, оценка SNR, доля
   тишины) — предупреждения печатаются сразу, плохой референс виден до синтеза;
3. Whisper расшифровывает запись, даёт язык и тайминги (без него — энергетический
   VAD, `--no-asr`);
4. сегменты ранжируются по уверенности ASR, склеиваются до 3–15 с и отбираются
   до `--ref-seconds` секунд чистой речи;
5. клипы обрезаются по тишине, выравниваются по громкости и пишутся в профиль.

```
profiles/anna/
    profile.json        метаданные, отчёт о качестве, выбранные сегменты
    transcript.json     полный вывод ASR
    refs/ref_01.wav     очищенные эталонные клипы, 24 кГц моно
    cache/xtts_latents.pt   кеш GPT-латентов и эмбеддинга диктора
```

Кеш латентов считается один раз и переиспользуется при каждом следующем
синтезе; если набор клипов изменился, он пересчитывается автоматически.

## Требования к железу

Замеры ниже сделаны на 4 vCPU без GPU (silero-stress) либо взяты как
ориентировочные для остального — цифры зависят от модели и длины текста.

| шаг | CPU (4 ядра) | GPU |
|-----|--------------|-----|
| silero-stress | загрузка 2.8 с, ~90 мс на фразу (измерено) | не нужен |
| faster-whisper `small` | ~0.3–0.5× RTF, int8 | ~0.05× RTF |
| XTTS-v2 синтез | ~1–3× RTF (медленнее реального времени) | ~0.1–0.3× RTF на RTX 3060+ |
| Silero TTS | ~0.1–0.3× RTF | не нужен |

Память: silero-stress ~1 ГБ RAM, Whisper `small` ~1 ГБ, XTTS-v2 ~4 ГБ VRAM
(или ~8 ГБ RAM на CPU). Диск: ~2 ГБ на веса XTTS + ~0.5 ГБ на Whisper.

**Про диалог в реальном времени.** Этот проект — пакетный синтез: он ждёт весь
текст, режет его на чанки и пишет файл. Для живого диалога (речь → ответ →
речь с задержкой до ~1 с) нужны потоковый режим и другое железо:

* GPU уровня RTX 3090/4090 или A10/L4 (24 ГБ) — тогда XTTS даёт RTF ≈ 0.1–0.2
  и первый звук через 200–400 мс при потоковой генерации
  (`Xtts.inference_stream`), плюс параллельно помещаются ASR и LLM;
* RTX 3060/4060 (8–12 ГБ) хватит на связку «Whisper small + XTTS» с задержкой
  порядка 0.7–1.5 с, если LLM внешняя;
* только CPU (8+ ядер): реальное время достижимо с Silero TTS (без
  клонирования, RTF ≈ 0.1–0.3), но не с XTTS;
* к задержке синтеза добавляются ASR (~100–300 мс), LLM (обычно главный вклад)
  и сеть. Ударения силеро на этом фоне почти бесплатны (~90 мс на фразу) и
  кешируются.

Потоковый режим в этом проекте пока не реализован — бэкенд отдаёт готовый
массив сэмплов. Точка расширения для стриминга: `TTSBackend.synthesize`.

## Расширение

**Новый язык** — данными, без правки кода:

```bash
cat > langs.json <<'EOF'
{"languages": [
  {"code": "de", "name": "German", "aliases": ["deu"],
   "whisper_code": "de", "xtts_code": "de", "normalizer": "generic"}
]}
EOF
vctts speak --language-config langs.json -l de -v sample.mp3 -t "Guten Tag!"
```

Или из Python:

```python
from voice_clone_tts.text.languages import LanguageSpec, register_language

register_language(LanguageSpec(
    code="uk", name="Ukrainian", aliases=("ukr",),
    whisper_code="uk", stress_provider="silero", stress_lang="ukr",
))
```

Поля `stress_provider`/`stress_lang` включают акцентор (silero-stress
поставляет `ru`, `ukr`, `bel`), `normalizer` выбирает правила чисел и
сокращений (`ru`, `en`, `generic`), `xtts_code` — код языка для XTTS.

**Новый бэкенд**:

```python
from voice_clone_tts.backends import TTSBackend, register_backend
from voice_clone_tts.text.stress import StressStyle

@register_backend
class MyBackend(TTSBackend):
    name = "my-tts"
    supported_languages = {"ru", "en"}
    clones_voice = True
    native_stress_style = StressStyle.PLUS   # какой вид разметки вам нужен
    sample_rate = 24_000

    def load(self):
        self.model = ...            # тяжёлый импорт только здесь
        super().load()

    def synthesize(self, request):  # -> np.ndarray float32, моно
        return self.model(request.text, request.profile.reference_paths())
```

`vctts speak -b my-tts …` подхватит его сразу, как и `--backend-option k=v`.

## Python API

```python
from voice_clone_tts import PipelineConfig, build_profile, synthesize

config = PipelineConfig()
config.synthesis.backend = "xtts"
config.asr.model = "medium"

profile = build_profile("sample.mp3", out_dir="profiles/anna", config=config)
print(profile.describe())

result = synthesize(profile=profile, text="Привет!", out_path="out.wav", config=config)
print(result.describe(), result.prepared_text, sep="\n")
```

## Качество: что реально влияет

* 30–60 секунд чистой речи одного человека дают заметно лучший результат, чем
  5 секунд; больше 2–3 минут почти ничего не добавляют;
* музыка, реверберация и шум клонируются вместе с голосом — их лучше убрать
  до подачи на вход;
* клиппинг (перегруз) портит тембр сильнее, чем тихая запись: предупреждения
  из отчёта о качестве стоит читать;
* для длинных текстов уменьшайте `--max-chars`, если слышите «зацикливание»
  в конце фраз (типичная болезнь авторегрессионных TTS).

## Этика и право

Клонирование голоса требует согласия человека, чей голос клонируется. Во
многих юрисдикциях голос — персональные данные и объект смежных прав, а выдача
синтезированной речи за настоящую может быть противоправной. Веса XTTS-v2
разрешены только для некоммерческого использования (CPML). Проверяйте, что у
вас есть право на исходную запись.
