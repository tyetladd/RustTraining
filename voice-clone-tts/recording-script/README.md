# Текст для начитки эталона

Материал для записи голоса, который потом пойдёт на обучение модели. Читаного
текста здесь примерно на **16–20 минут**, плюс блок свободной речи на 5–8 минут:
вместе это как раз те 20–25 минут чистой речи, на которых voice conversion
обучается уверенно.

Блоки специально разные. Модель выучивает только те звуки и интонации, которые
услышала: если начитать двадцать минут ровной прозы, синтез и будет звучать как
ровная проза, а на вопросе или числе споткнётся.

| файл | что это | минут |
|------|---------|-------|
| `00-kalibrovka.md` | проба для настройки микрофона, не для обучения | 0,5 |
| `01-proza.md` | нейтральное повествование — основа | 1,8 |
| `02-rasskaz.md` | рассказ от первого лица, живее | 1,6 |
| `03-voprosy.md` | вопросы, восклицания, короткие реплики | 1,0 |
| `04-chisla.md` | числа, даты, единицы, суммы | 1,5 |
| `05-imena.md` | имена, города, заимствования | 1,5 |
| `06-delovoy.md` | деловой и технический текст, длинные фразы | 1,5 |
| `07-razgovor.md` | разговорные фразы и прямая речь | 1,1 |
| `08-fonetika.md` | трудные звуки и сочетания | 1,2 |
| `09-periody.md` | длинные периоды и перечисления | 1,9 |
| `10-instrukciya.md` | пояснения по шагам, бытовая речь | 1,4 |
| `11-svobodnaya-rech.md` | темы для импровизации (текста нет намеренно) | 5–8 |

Оценка минут — при темпе около 140 слов в минуту; если читаете медленнее,
получится больше.

## Форматы

* **`NN-*.md`** — для чтения с экрана: заголовки, ремарки курсивом, видно,
  где блок начинается и заканчивается. Основной рабочий формат.
* **`vsyo-podryad.txt`** — то же самое подряд, без разметки и ремарок: для
  телепромптера, распечатки или второго монитора.
* **`test-frazy.md` / `test-frazy.txt`** — не для записи. Это то, что надо
  синтезировать **после** обучения, чтобы услышать типичные проблемы.

Файлы `.txt` генерируются из `.md`, а не правятся руками:

```bash
python3 recording-script/make_plaintext.py
```

## Порядок записи

1. Настройте микрофон и запишите `00-kalibrovka.md` отдельным файлом.
2. Прогоните пробу через проверку и при необходимости поправьте уровень:
   ```bash
   vctts check kalibrovka.wav --purpose vc
   ```
   Смотреть надо на клиппинг, SNR и пик; замечание про длительность на пробе
   ожидаемо.
3. Запишите блоки 01–10 **одним файлом**, не меняя положение микрофона.
   Паузы между блоками не страшны — они вырезаются автоматически.
4. Не выключая запись, наговорите блок 11 своими словами.
5. Проверьте итоговый файл целиком:
   ```bash
   vctts check zapis.wav --purpose vc
   ```

## Как читать

* Обычным голосом. «Дикторская» подача даст модель, которая умеет только
  дикторскую подачу.
* Ровные темп и громкость: не разгоняйтесь к концу блока и не затихайте.
* Сбились — не начинайте файл заново, просто перечитайте фразу и продолжайте.
* Не делайте искусственных пауз между предложениями, но и не склеивайте их.
* Вода рядом: двадцать минут чтения сушат горло сильнее, чем кажется.
* Если запись растянулась на два дня — лучше начать заново в один присест:
  разные условия записи в одном датасете портят результат сильнее, чем
  недостаток минут.

## После обучения

```bash
vctts speak -b silero --voice-model voices/anna --transpose auto \
      -f recording-script/test-frazy.txt -o proverka.wav
```

Набор подобран так, чтобы вылезли ошибки: омографы (`замок` / `замок`), числа и
даты, интонация вопроса, длинное дыхание, трудные сочетания согласных. Ожидаемое
чтение омографов указано в `test-frazy.md`.
